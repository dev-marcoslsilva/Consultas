# Consultas
Um repositório público que contém as consultas que eu faço em um banco de dados a partir de regras de negócio estabelecidas

Seja bem-vindo! Nesse repositório, você encontrará consultas que eu fiz para diversos bancos de dados, tanto o meu objetivo quanto o código sql. Assim está divida a estrutura de pastas que você encontrará aqui:

      - Consultas
        - Nome_do_banco
          -target.txt
          -consulta.sql

Em que:

Consultas é a pasta raíz, que armazena todas as consultas
Nome_do_banco é o nome do banco de dados no qual as consultas estão sendo realizadas
target é o arquivo que contém o que está sendo procurado
consulta é o código sql
